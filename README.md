# NekoStream

Website streaming anime sederhana yang menggunakan API publik dari `https://nexora-anime-api.vercel.app/` dengan sumber data Oploverz.

## Cara Pakai

1. Ekstrak folder `NekoStream`.
2. Buka file `index.html` di browser (Chrome, Firefox, dll).
3. Data akan otomatis dimuat dari API.

## Catatan

- Website ini hanya menampilkan daftar anime. Link streaming mengarah ke situs sumber (`oploverz.am`).
- API bisa berubah atau down sewaktu-waktu. Kalau data kosong, coba refresh beberapa saat lagi.

## Teknologi

- HTML
- CSS
- JavaScript (Vanilla)
